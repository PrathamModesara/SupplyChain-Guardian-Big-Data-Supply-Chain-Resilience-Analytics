# SupplyChain Guardian

## Big Data Supply Chain Resilience Analytics

SupplyChain Guardian is a Big Data Analytics platform designed to analyze supply chain risks, operational performance, transportation networks, inventory conditions, and disruption events.

## Technologies

- Hadoop HDFS
- Apache Spark
- Spark SQL
- GraphX
- PySpark
- Python
- Machine Learning
- Power BI

## Dataset

The project uses a large-scale integrated supply chain dataset containing approximately 205,786 records and 88 features.

The raw dataset is intentionally excluded from GitHub because of its large file size.
